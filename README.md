# EMO STORE | متجر إلكتروني عربي

متجر إلكتروني عربي احترافي (RTL) مبني بـ **FastAPI + SQLite**، بواجهة عميل كاملة ولوحة تحكم أدمن مدمجة، بدون أي خطوة build.

---

## المميزات

### واجهة المتجر
- تصميم عربي RTL بهوية بصرية كاملة (كريمي + أخضر غامق + ذهبي، خطوط Cairo وAmiri).
- صفحة رئيسية، تصفح الأقسام، بحث، فلترة وترتيب المنتجات.
- صفحة منتج بتفاصيل المقاسات والألوان والمخزون ومعرض صور.
- سلة تسوق محفوظة في `localStorage` مع drawer جانبي.
- إتمام طلب من خطوة واحدة مع 27 محافظة ورسوم شحن لكل محافظة.
- طرق دفع افتراضية: الدفع عند الاستلام، إنستاباي، محفظة إلكترونية — ويمكن إضافة طرق أخرى أو إيقاف أي طريقة من لوحة التحكم.
- صفحة نجاح الطلب + صفحة تتبع الطلب برقم الطلب والهاتف.
- تصميم متجاوب بالكامل (موبايل / تابلت / ديسكتوب).

### لوحة التحكم (`/admin`)
- تسجيل دخول محمي بـ Bearer token موقّع (HMAC) وكلمات مرور PBKDF2.
- نظرة عامة بإحصائيات المبيعات والطلبات (بتوقيت المتجر `Africa/Cairo`).
- إدارة الطلبات: عرض التفاصيل، تغيير الحالة، تحديث حالة الدفع. عند تحويل أي طلب إلى **ملغي** تُرَجَّع كمياته للمخزن تلقائيًا مرة واحدة فقط.
- إدارة المنتجات: إضافة/تعديل/حذف/إظهار وإخفاء، رفع صور، بحث وترقيم صفحات.
- إدارة الأقسام: إضافة/تعديل/حذف مع ترتيب الظهور.
- إعدادات المتجر: تعديل الاسم والاسم الإنجليزي والشعار والعملة وبيانات الدفع.
- بيانات التواصل والروابط: تعديل الهاتف والإيميل والواتساب والعنوان وساعات العمل ولينكي إنستجرام وفيسبوك من الإعدادات، وتظهر مباشرة في فوتر المتجر.
- إدارة طرق الدفع: تفعيل/إيقاف أي طريقة، إضافة طريقة جديدة باسم ووصف وأيقونة وترتيب، مع منع تعطيل آخر طريقة متاحة.
- إدارة الشحن: تشغيل/إيقاف الشحن المجاني وتحديد حده، وتعديل رسوم كل محافظة، وإيقاف الشحن لمحافظات معينة.
- واجهة متجاوبة مع sidebar منزلق على الشاشات الصغيرة.

## التشغيل

### أسهل طريقة (ويندوز)

- **`start.bat`** — دبل كليك: يشغّل الخادم ويفتح المتصفح تلقائيًا.
- **`start-mobile.bat`** — دبل كليك: يشغّل الخادم متاحًا للموبايل على نفس الواي فاي ويطبع عنوان الشبكة.

> لو الخادم شغال بالفعل، `start.bat` بيفتح المتصفح بس من غير ما يشغّل نسخة تانية.

### من الطرفية

```bash
cd ecommerce-backend
python -m pip install -r requirements.txt
python run.py
```

لتجربة المتجر من الموبايل على نفس شبكة الواي فاي:

```powershell
$env:HOST="0.0.0.0"
python run.py
```

ثم افتح `http://<IP-الكمبيوتر>:8050` من الموبايل (مثال: `http://192.168.1.10:8050`).
> احتفظ بالخادم على `127.0.0.1` لو مش محتاج الوصول من أجهزة تانية.

> **ملاحظة:** سيب نافذة الخادم مفتوحة. لو قفلتها الخادم بيقف. لو عايز إعادة تحميل تلقائي أثناء التطوير شغّل `set RELOAD=1` قبل `python run.py`.

ثم افتح:

| الصفحة | الرابط |
| --- | --- |
| المتجر | http://127.0.0.1:8050/ |
| لوحة التحكم | http://127.0.0.1:8050/admin |
| توثيق API | http://127.0.0.1:8050/api/docs |

### بيانات الدخول الافتراضية

```
اسم المستخدم: admin
كلمة المرور:  admin123
```

> غيّر كلمة المرور من صفحة الإعدادات بعد أول تشغيل، وغيّر `SECRET_KEY` في بيئة الإنتاج.

## النشر لايف (Render)

> ⚠️ **Streamlit Cloud مش بديل عن الـ Backend.** الموقع الأصلي FastAPI + HTML/JS، محتاج سيرفر زي Render. اللي على Streamlit (`streamlit_app.py`) مجرد واجهة/لوحة بتكلم الـ API عبر `API_BASE_URL`. لو وقّفت Render، الواجهة مش هتشغل.

الطريقة الأسهل (Blueprint):

1. ارفع آخر تعديلات للـ GitHub (لازم ملف `render.yaml` يكون في جذر الـ repo).
2. افتح https://render.com → **New → Blueprint** → اختار الـ repo.
3. Render هيقرأ `render.yaml` وينشئ خدمة اسمها `aseel-store` تلقائيًا.
4. بعد ماDeploy يخلص، افتح الرابط اللي هيطلع لك:
   - المتجر: `https://aseel-store.onrender.com/`
   - لوحة التحكم: `https://aseel-store.onrender.com/admin`
   - توثيق API: `https://aseel-store.onrender.com/api/docs`

> لو اسم الخدمة اتاخد، غيّر `name` في `render.yaml` قبل الرفع.

**مهم قبل النشر الفعلي:**
- غيّر `ADMIN_PASSWORD` و `SECRET_KEY` من **Environment** في لوحة Render.
- الخطة المجانية بتنام بعد فترة عدم استخدام، أول طلب بعدها بياخد 30–60 ثانية (دى طبيعية مش خطأ في الكود). الحلول:
  - استنى شوية واعمل Refresh.
  - شغّل Ping كل 5 دقائق من UptimeRobot على `https://aseel-store.onrender.com/api/health`.
  - أو ترقّى لخطة Starter عشان الخدمة تفضل شغالة طول الوقت.
- قاعدة البيانات SQLite الحالية بتترجع للبيانات الافتراضية بعد إعادة النشر/التشغيل. لو عايز بيانات دائمة، هنضيف Postgres لاحقًا.

## واجهة Streamlit Cloud (اختياري)

لو عايز رابط على `share.streamlit.io`، استخدم `streamlit_app.py` الموجود في جذر الـ repo:

1. افتح https://share.streamlit.io → **New app** → اختار repo `ar8040202/App-Store`.
2. **Main file path:** `streamlit_app.py`.
3. من **App settings → Secrets** ضيف:
   ```toml
   API_BASE_URL = "https://aseel-store.onrender.com"
   ```
4. **Deploy**.

الواجهة فيها: عرض المنتجات، تسجيل دخول الأدمن، عرض الطلبات وتغيير حالتها (الإلغاء بيرجّع المخزن)، وتعديل إعدادات المتجر.

> Streamlit Cloud المجاني كمان بي نام بعد عدم استخدام، فأول فتح بياخد ثواني. والـ Backend لازم يفضل شغال على Render.

## متغيرات البيئة

| المتغير | الافتراضي | الوصف |
| --- | --- | --- |
| `SECRET_KEY` | قيمة تطويرية | مفتاح توقيع tokens الأدمن |
| `ADMIN_USERNAME` | `admin` | اسم مستخدم الأدمن عند أول seed |
| `ADMIN_PASSWORD` | `admin123` | كلمة مرور الأدمن عند أول seed |
| `TOKEN_TTL_HOURS` | `12` | مدة صلاحية token الأدمن |
| `STORE_TIMEZONE` | `Africa/Cairo` | توقيت حساب إحصائيات اليوم |
| `HOST` | `127.0.0.1` | `0.0.0.0` للوصول من أجهزة أخرى على نفس الشبكة |
| `PORT` | `8050` | منفذ تشغيل الخادم (القيمة الافتراضية في `settings.py`) |
| `RELOAD` | `0` | `1` لتشغيل إعادة التحميل التلقائي أثناء التطوير |
| `API_BASE_URL` | `https://aseel-store.onrender.com` | رابط الـ Backend المستخدم من واجهة Streamlit |

> المنفذ مكتوب مرة واحدة في `settings.py`، وملفات `start.bat` / `start-mobile.bat` بتقرأه منه. لتغييره: عدّل `PORT = 8050` في `settings.py` أو شغّل `set PORT=8051` قبل `python run.py`.

## هيكل المشروع

```
ecommerce-backend/
├── main.py                 # نقطة تشغيل FastAPI + seed + static mount
├── run.py                  # تشغيل uvicorn
├── settings.py             # القيم الافتراضية للمتجر والشحن والدفع
├── store_config.py         # إعدادات المتجر والمحافظات المحفوظة في قاعدة البيانات
├── database.py             # engine + session
├── models.py               # جداول SQLAlchemy
├── schemas.py              # Pydantic v2 schemas
├── security.py             # PBKDF2 + HMAC tokens
├── seed.py                 # بيانات تجريبية (6 أقسام / 19 منتج / أدمن)
├── deps.py                 # dependencies (DB / admin auth)
├── utils.py                # أدوات مساعدة
├── routers/
│   ├── auth.py             # login / me / change password
│   ├── catalog.py          # منتجات وأقسام وبيانات المتجر
│   ├── orders.py           # إنشاء الطلب وتتبعه
│   └── admin.py            # كل عمليات الأدمن والإحصائيات
├── static/
│   ├── index.html          # واجهة المتجر
│   ├── admin.html          # لوحة التحكم
│   ├── css/                # base / style / admin
│   ├── js/                 # api / icons / store / app / admin
│   ├── img/                # صور المنتجات والأقسام
│   └── uploads/            # صور مرفوعة من لوحة التحكم
├── legacy_streamlit_app.py # لوحة Streamlit القديمة (مهملة، مرجع فقط)
├── ecommerce.db            # قاعدة SQLite (تُنشأ تلقائيًا)
└── ecommerce.db.bak        # نسخة احتياطية من قاعدة قديمة (غير مستخدمة)
```

## ملاحظات

- قاعدة البيانات تُنشأ وتُملأ تلقائيًا عند أول تشغيل إذا كانت فارغة.
- إعادة ضبط المتجر: احذف `ecommerce.db` ثم شغّل الخادم من جديد.
- الصور الافتراضية محفوظة محليًا داخل `static/img`، والصور المرفوعة تُحفظ في `static/uploads`.
- الشحن مجاني افتراضيًا للطلبات فوق **1,500 ج.م**، ويمكن تغييره أو إيقافه من صفحة **الإعدادات** في لوحة التحكم. لو خلّيت الحد **صفر**، الشحن يبقى مجاني لكل الطلبات.
- المحافظات الموقوفة من الشحن لا تظهر للعميل في صفحة إتمام الطلب، ورسوم كل محافظة تُعدّل من جدول الشحن في الإعدادات.
- طرق الدفع الموقوفة لا تظهر للعميل في صفحة إتمام الطلب، وأي طريقة دفع جديدة تُضاف من **الإعدادات → طرق الدفع**. لازم تفضل طريقة واحدة نشطة على الأقل، وحذف طريقة مرتبطة بطلبات سابقة بيوقفها بدل حذفها.
- الملف `legacy_streamlit_app.py` لا يعمل مع الـ API الحالي؛ لوحة `/admin` هي البديل.
